# XJTLU-VLN-E2E

面向 XJTLU 自动驾驶小车的团队视觉语言导航科研项目与代码仓库。

当前项目处于文献阅读、方法比较、仿真复现和研究问题探索阶段。研究方案尚未锁定，后续可能比较不同的视觉表示、空间记忆、地图使用方式、推理机制和动作接口。

## 当前探索方向

- `3dgs-vln`：研究 3D Gaussian Splatting、空间表示与 VLN 的可能结合方式；
- `spatial-intelligence-reasoning`：研究有限视角下的空间智能、空间推理和 VLN 可能结合方式。

两个分支是探索方向，不预先规定最终的输入、输出、地图使用方式或动作空间。

拓扑图/航点方向由团队在独立仓库 `ETPNav-MID360` 中维护；前视 RGB-LiDAR 方向由团队在独立仓库 `FrontRGB-LiDAR-VLN` 中维护。相关方法可以作为文献和对照参考，但不自动成为本项目的研究结论。

## 当前范围

当前只关注文献阅读、方法探索、仿真复现和算法实验。真实车辆、底盘、ROS 运行链路、硬件参数和实车部署暂时不纳入当前工作；相关内容保持原样。

## 当前阶段

- 阅读相关论文，整理任务、输入、输出、动作空间、数据和实验；
- 在 Habitat-HM3D 中复现论文原始任务和动作空间；
- 比较不同研究假设，再决定后续模型和实验方向；
- 真实硬件和部署参数仍需单独核实。
